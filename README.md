# 🚀 Task Management System

A modern Task Management System built using **Mendix Studio Pro 10.24.21**.

This application allows managers to assign tasks to employees, monitor task progress, review completed work, and provide feedback through a modern dashboard interface.

---

# 📖 Project Overview

The Task Management System is a role-based web application developed using the Mendix low-code platform.

The system simplifies task assignment, employee tracking, approval management, and reporting.

The application supports three user roles:

- Administrator
- Manager
- Employee

Each role has its own dashboard and permissions.
